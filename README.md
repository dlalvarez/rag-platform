# RAG Platform

Plataforma SaaS multi-tenant, multiusuario, multirrepositorio y multiasistente de recuperación documental y asistentes inteligentes basada en RAG.

Este repositorio se desarrollará mediante **Specification-Driven Development (SDD)**, con decisiones arquitectónicas documentadas, ramas de trabajo y Pull Requests.

La especificación fundacional está registrada inicialmente en [Issue #1](https://github.com/dlalvarez/rag-platform/issues/1). No se deben incorporar secretos ni credenciales al repositorio.
