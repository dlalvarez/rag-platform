# Constitución — referencia canónica

La **única constitución normativa** de RAG Platform es [docs/01-constitution.md](docs/01-constitution.md), con los principios P01–P14.

Este archivo existe únicamente como punto de entrada desde la raíz del repositorio. La constitución abreviada incorporada en PR #2 se conserva para trazabilidad en [docs/history/pr2/CONSTITUTION.md](docs/history/pr2/CONSTITUTION.md); **no** tiene autoridad paralela.

Cambios de arquitectura requieren ADR y aprobación humana conforme a la constitución.
