# ADR 0003 — SDD y GitHub como fuentes de especificación y evidencias

**Estado:** Aprobación metodológica del usuario recogida en conversación.

**Decisión:** Constitución, ADRs, specs por fase, plan, tareas, aceptación y pruebas por PR. Codex puede crear propuestas/PRs pero no cambia arquitectura ni fusiona sin aprobación.

**Consecuencias:** disciplina de trazabilidad y revisión por fases; velocidad controlada frente a cambios improvisados.


## Actualización de autorización (2026-10-31)

hacia develop, por la delegación acotada aprobada en [ADR-0007](0007-delegated-development-review.md).
